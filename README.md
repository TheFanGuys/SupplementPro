# Supplement Guide

Searchable supplement list showing the different forms of each supplement and the best time of day to take it. Build your own plan.

**Open it:** https://thefanguys.github.io/SupplementPro/

Your data is saved on your phone only (in Safari). It is not stored in this repo.

Single-file app (index.html), no build step. Hosted on GitHub Pages. Upload a new index.html to update it.
